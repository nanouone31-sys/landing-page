# صفحة هبوط FIXTOP

ملف واحد جاهز: `index.html` (يحتوي كل الـ CSS و JS بداخله، بدون أي مكتبات خارجية).

## قبل النشر، عدّل هذه النقاط:

1. **رقم واتساب**: في `index.html` ابحث عن `WHATSAPP_NUMBER` (داخل `<script>` في الأسفل) وضع رقمك الحقيقي بصيغة دولية بدون `+` أو `00`، مثال: `213555123456`.
2. **الصور**: ضع صور المنتج الحقيقية داخل مجلد `images/` بهذه الأسماء:
   - `images/hero.jpg` (الصورة الرئيسية)
   - `images/gallery-1.jpg` إلى `images/gallery-4.jpg` (صور تفصيلية)
   إلى أن تضيفها، تظهر عناصر نائبة رمادية تلقائيًا فلا تنكسر الصفحة.
3. **الأسعار**: ابحث عن `18900` و `26900` وعدّلهما إذا تغيّر السعر (كذلك `UNIT_PRICE` في الـ JS).
4. **تسجيل الطلبات فعليًا**: النموذج حاليًا يعرض رسالة نجاح فقط ويفتح واتساب، ولا يرسل البيانات لأي سيرفر. لتسجيل الطلبات (Google Sheet، API، إلخ) أضف الاستدعاء داخل معالج `submit` في الـ JS (المكان مُعلَّم بتعليق).

## الاستضافة
ارفع `index.html` (ومجلد `images`) على أي استضافة ثابتة (GitHub Pages, Netlify, Vercel...) واستخدم الرابط في إعلانات فيسبوك.
